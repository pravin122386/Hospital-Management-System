# Hospital Management System

A console-based Hospital Management System developed using C++ and STL concepts.

## Features

- Add Patient Records
- Search Patient Details
- Process Outpatient and Emergency Patients
- Medication and Prescription Handling
- Billing System
- Patient History Tracking
- Emergency Buffer Management
- Queue-Based Patient Processing

## Technologies Used

- C++
- File Handling
- Queue
- Priority Queue
- STL Containers
- Object-Oriented Programming

## Files Used

- `main.cpp` → Main source code
- `patients.txt` → Stores patient details
- `history.txt` → Stores patient history and billing

## How to Run

### Compile

```bash
g++ main.cpp -o hospital
```

### Run

#### Windows
```bash
hospital.exe
```

#### Linux / Mac
```bash
./hospital
```
